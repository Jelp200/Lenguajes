# Ejercicios de Fundamentos de Programación en C 📚

A continuación se presentan ejercicios para cada uno de los temas fundamentales de programación en C. Cada sección contiene al menos 5 ejercicios para practicar y afianzar los conceptos.

---

## 1. Estructura General de un Programa en C

1. Escribe un programa que imprima tu nombre y edad.
2. Modifica el programa anterior para que imprima tu dirección.
3. Escribe un programa que imprima el mensaje "¡Bienvenido a C!".
4. Crea un programa que imprima tres líneas diferentes de texto.
5. Escribe un programa que imprima el resultado de sumar dos números fijos.

---

## 2. Hola Mundo

1. Escribe el clásico programa "Hola Mundo".
2. Modifica el programa para que imprima "Hola, [tu nombre]!".
3. Haz que el programa imprima "Hola" en una línea y "Mundo" en otra.
4. Escribe un programa que imprima un mensaje personalizado usando printf.
5. Haz que el programa imprima un mensaje con caracteres especiales (\n, \t).

---

## 3. Variables

1. Declara una variable entera, asígnale un valor y muéstralo.
2. Declara una variable float, asígnale un valor y muéstralo.
3. Declara una variable char, asígnale una letra y muéstrala.
4. Declara dos variables, suma sus valores y muestra el resultado.
5. Intercambia el valor de dos variables y muestra los resultados antes y después.

---

## 4. Tipos de Datos

1. Declara variables de tipo int, float, double y char, y muestra sus valores.
2. Escribe un programa que muestre el tamaño en bytes de cada tipo de dato.
3. Realiza operaciones entre diferentes tipos de datos y muestra el resultado.
4. Convierte un valor float a int y muestra ambos valores.
5. Declara una variable unsigned int y muestra su valor máximo.

---

## 5. Entradas y Salidas

1. Escribe un programa que pida al usuario su nombre y lo imprima.
2. Solicita dos números al usuario y muestra su suma.
3. Pide al usuario un carácter y muéstralo en pantalla.
4. Solicita al usuario su edad y muestra un mensaje personalizado.
5. Pide al usuario tres números y muestra su promedio.

---

## 6. Operadores

1. Escribe un programa que sume, reste, multiplique y divida dos números.
2. Calcula el residuo de la división de dos números.
3. Usa operadores de incremento y decremento en una variable y muestra los resultados.
4. Realiza operaciones lógicas (&&, ||, !) y muestra los resultados.
5. Usa operadores de asignación compuesta (+=, -=, *=, /=) y muestra los resultados.

---

## 7. Funciones Matemáticas

1. Calcula la raíz cuadrada de un número ingresado por el usuario.
2. Calcula el valor absoluto de un número.
3. Calcula la potencia de un número elevado a otro.
4. Calcula el seno y coseno de un ángulo en radianes.
5. Redondea un número decimal al entero más cercano.

---

## 8. Post y Pre-Incremento

1. Muestra la diferencia entre pre-incremento y post-incremento en una variable.
2. Usa pre-decremento y post-decremento y muestra los resultados.
3. Escribe un ciclo que use post-incremento para contar del 1 al 5.
4. Escribe un ciclo que use pre-incremento para contar del 5 al 1.
5. Usa operadores de incremento en una expresión compleja y explica el resultado.

---

## 9. Estructuras Condicionales

1. Escribe un programa que determine si un número es positivo o negativo.
2. Determina si un número es par o impar.
3. Pide dos números y muestra el mayor.
4. Pide tres números y muestra el menor.
5. Escribe un programa que verifique si un año es bisiesto.

---

## 10. Estructuras de Control (Ciclos)

1. Imprime los números del 1 al 10 usando un ciclo while.
2. Imprime los números del 10 al 1 usando un ciclo for.
3. Suma los números del 1 al 100 usando un ciclo.
4. Imprime la tabla de multiplicar de un número ingresado por el usuario.
5. Calcula el factorial de un número usando un ciclo do-while.

---

## 11. Estructuras de Selección (switch)

1. Escribe un programa que lea un número del 1 al 7 y muestre el día de la semana.
2. Usa switch para realizar una calculadora básica (+, -, *, /).
3. Escribe un programa que lea una letra y determine si es vocal o consonante.
4. Usa switch para mostrar un mensaje según el mes del año.
5. Escribe un programa que lea una opción y ejecute una acción diferente según el valor.

---

## 12. Break y Continue

1. Escribe un ciclo que imprima los números del 1 al 10, pero se detenga al llegar al 5.
2. Escribe un ciclo que imprima los números del 1 al 10, pero omita el 5.
3. Usa break para salir de un ciclo infinito cuando se cumpla una condición.
4. Usa continue para saltar los números pares en un ciclo del 1 al 10.
5. Escribe un ciclo que sume números hasta que el usuario ingrese 0 (usa break).

---

## 13. Funciones

1. Escribe una función que sume dos números y retorne el resultado.
2. Escribe una función que calcule el área de un círculo.
3. Escribe una función que determine si un número es primo.
4. Escribe una función que imprima un mensaje de bienvenida.
5. Escribe una función que reciba un número y devuelva su cuadrado.

---

## 14. Funciones Recursivas

1. Escribe una función recursiva para calcular el factorial de un número.
2. Escribe una función recursiva para calcular la suma de los primeros n números naturales.
3. Escribe una función recursiva para calcular la serie de Fibonacci.
4. Escribe una función recursiva para invertir un número.
5. Escribe una función recursiva para calcular la potencia de un número.

---

## 15. Caracteres

1. Escribe un programa que determine si un carácter es una letra.
2. Escribe un programa que determine si un carácter es un dígito.
3. Escribe un programa que convierta una letra minúscula a mayúscula.
4. Escribe un programa que cuente cuántas letras mayúsculas hay en una cadena.
5. Escribe un programa que verifique si un carácter es un espacio en blanco.

---

## 16. Funciones Aleatorias

1. Escribe un programa que genere un número aleatorio entre 1 y 100.
2. Escribe un programa que simule el lanzamiento de un dado.
3. Escribe un programa que genere 10 números aleatorios y los imprima.
4. Escribe un programa que adivine un número aleatorio generado por la computadora.
5. Escribe un programa que genere una contraseña aleatoria de 8 caracteres.

---

## 17. Funciones de Cadenas (String)

1. Escribe un programa que copie una cadena en otra variable.
2. Escribe un programa que concatene dos cadenas.
3. Escribe un programa que compare dos cadenas y muestre si son iguales.
4. Escribe un programa que calcule la longitud de una cadena.
5. Escribe un programa que invierta una cadena.

---

## 18. Arreglos

1. Escribe un programa que almacene 5 números en un arreglo y los imprima.
2. Escribe un programa que calcule la suma de los elementos de un arreglo.
3. Escribe un programa que encuentre el mayor elemento de un arreglo.
4. Escribe un programa que ordene un arreglo de números enteros.
5. Escribe un programa que multiplique dos matrices de 2x2.

---

## 19. Apuntadores

1. Escribe un programa que muestre la dirección de memoria de una variable.
2. Escribe un programa que use un apuntador para modificar el valor de una variable.
3. Escribe un programa que intercambie el valor de dos variables usando apuntadores.
4. Escribe un programa que recorra un arreglo usando apuntadores.
5. Escribe un programa que pase un arreglo a una función usando apuntadores.

---

## 20. Estructuras, Uniones y Enumeraciones

1. Define una estructura para almacenar los datos de un estudiante e imprímelos.
2. Escribe un programa que use una unión para almacenar diferentes tipos de datos.
3. Escribe un programa que use una enumeración para los días de la semana.
4. Escribe un programa que almacene varios estudiantes en un arreglo de estructuras.
5. Escribe un programa que use una estructura anidada.

---

## 21. Nuevos Tipos de Datos

1. Define un nuevo tipo de dato para representar una fracción.
2. Escribe un programa que use typedef para simplificar la declaración de estructuras.
3. Escribe un programa que defina un tipo booleano y lo use.
4. Escribe un programa que defina un tipo de dato para coordenadas (x, y).
5. Escribe un programa que use typedef para definir un tipo de dato para matrices.

---

## 22. Entradas y Salidas Estándar

1. Escribe un programa que lea una línea completa de texto y la imprima.
2. Escribe un programa que lea caracteres hasta que se presione Enter.
3. Escribe un programa que lea y escriba datos en un archivo de texto.
4. Escribe un programa que cuente cuántas palabras hay en una línea de texto.
5. Escribe un programa que lea números de un archivo y calcule su suma.
